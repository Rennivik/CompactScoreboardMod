# **Compact Scoreboard**

A _client-side_ mod that shortens large scoreboard numbers into a more readable format on the sidebar. Values are converted into compact forms like **K**, **M**, and **B** to reduce clutter while keeping important information visible.

Full numbers can be _temporarily_ shown by holding a configurable keybind.

- 1,000 → 1K
- 1,000,000 → 1M
- 1,000,000,000 → 1B

Designed to keep the scoreboard clean without removing detail when you need it.
